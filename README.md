## ✨ 核心功能

1. **手机号与身份信息随意编辑**
   - 支持任意手机号码、座机固话、客服短号或“未知号码”，支持一键 `3-4-4` 空格排版；
   - 备注姓名留空时以大字号直接显示手机号；填写姓名后主标题显示姓名、副标题显示手机号与归属地。
2. **三大核心界面自由切换 & 真实交互**
   - **【来电显示】**：安卓版支持呼吸波纹双圆键；iOS 版支持 **锁屏「滑动来接听」滑块** 与 **亮屏「拒绝/接听」双圆键** 自由切换；
   - **【已接通】**：支持自定义起始计时秒数（如从 `00:00` 或 `01:28` 起跳），内置静音、免提、录音计时、拨号键盘（可展开真实拨号盘并带按键音）六宫格；
   - **【未接通】**：支持一键切换或自定义 `未接来电`、`无人接听`、`对方忙线`、`呼叫失败`、`通话结束`、`正在呼叫…` 等文案。
3. **拍摄防穿帮设计**
   - 支持 **3秒 / 5秒 / 10秒黑屏延时来电**：点击后进入纯黑息屏状态，倒计时结束自动亮屏响铃震动；
   - 进入通话界面后无任何多余控制按钮，**双击屏幕最顶部状态栏（时间/信号区域）** 或 **连按两次安卓物理返回键** 即可返回编辑控制台。

## 📲 安装使用指南

### 🍎 iPhone / iOS 安装为全屏独立 APP（免签、永不掉签）
- **方式一（Safari 添加到主屏幕，最简单）**：
  1. 用 iPhone 自带的 **Safari 浏览器** 打开 [`https://xunbaodedashu.github.io/call-simulator/ios.html`](https://xunbaodedashu.github.io/call-simulator/ios.html)；
  2. 点击底部正中间的 **「分享」图标** ➔ 向下滑动选择 **「添加到主屏幕」**；
  3. 从 iPhone 桌面点开「模拟来电」图标，即为 **100% 全屏无地址栏** 的独立 APP。
- **方式二（WebClip 描述文件安装）**：
  1. 在 Safari 点击下载 [`ios-install.mobileconfig`](https://xunbaodedashu.github.io/call-simulator/ios-install.mobileconfig) 或离线版 [`模拟来电_iOS桌面图标安装.mobileconfig`](./模拟来电_iOS桌面图标安装.mobileconfig)；
  2. 打开 iPhone「设置」➔ 顶部「已下载描述文件」➔ 点击「安装」，桌面即生成全屏图标。

### 🤖 Android 安装
- 直接下载仓库根目录或 Releases 中的 [`模拟来电_UCN_MQ_Z.apk`](./模拟来电_UCN_MQ_Z.apk) 安装即可（支持 Android 7.0 ~ 15+，已含 v2/v3 正式签名）。
- 如需二次修改打包，在 Windows 下运行 `android-project/一键编译APK.ps1` 即可快速重新生成签名 APK。
